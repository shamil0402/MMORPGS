
# MMORPG Game Project

## Overview
This is a multiplayer online role-playing game (MMORPG) where players can create characters, explore a virtual world, fight monsters, complete quests, collect items, and interact with other players in real time.
 please check this- https://drive.google.com/drive/folders/1NX5fKwHn7BY-j802CUv9mtXo9pNnpXua?usp=sharing
## Features
- Multiplayer online gameplay
- Character creation and customization
- Real-time combat system
- Open-world exploration
- Monster and NPC systems
- Inventory and equipment management
- Leveling and experience system
- Quest and mission system
- Player-to-player interaction
- Chat system
- Guild and party systems

## Technologies
### Client
- Android
- Unity
- C#

### Backend
- Java / Spring Boot
- WebSocket
- REST API

### Database
- MySQL
- Redis

## Installation

1. Clone the repository.
2. Open the Android client project.
3. Configure the backend server.
4. Set up the MySQL database.
5. Configure server connection settings.
6. Build and run the Android application.

## Requirements
- Android Studio
- Unity
- JDK 17+
- MySQL
- Maven
